## Extended description

A Claude skill built under the TABARC-Code author identity, covering the complete professional workflow for magazine and newspaper feature writing.

The skill was built source-first — seven books on magazine journalism craft were fully ingested, audited for coverage gaps, and distilled into operational guidance. The result isn't a style guide or a set of generic writing tips. It's the kind of reference a working journalist would actually reach for: specific, argued, and honest about where the easy advice runs out.

Three full audit cycles were run on the first build. The audit found ten significant gaps — the freelance business mechanics, named structural models, the nut graf in any real depth, the short fiction workflow, writer specialisation strategy, and several others. All were addressed. The modules were then cross-wired — a step that turned fourteen isolated files into one coherent skill. Because it had originally been built as fourteen isolated files.

The skill is structured as one master `SKILL.md` routing nine reference modules and five subskills. Every module ends with a `→ Where this module leads` section giving specific contextual handoffs to the next relevant module. The Kaizen continuous improvement philosophy is threaded throughout — not decoratively but operationally, with an improvement loop, a personal standards document template, and compound effect tracking.

Built to the TABARC-Code conventions: YAML frontmatter, explicit version tracking, bidirectional relationships, UK English.
